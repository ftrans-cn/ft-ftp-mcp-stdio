## 3. 发布范围与构建链路复核

- `pyproject.toml`、`uv.lock`、运行时 `__version__` 和 FastMCP `mcp.version` 均为 `0.3.0`；MCP 版本已改为引用运行时版本定义。
- README、当前 Spec、配置 Schema、架构文档、用户手册和产品能力清单均包含 0.3.0 适用版本。历史发布说明、历史执行证据和测试中的旧版本字符串属于可追溯记录或负向断言，不是混入当前发布的版本源。
- 发布范围明确为 Windows 10/11 x64、Python 3.12 的离线完整 ZIP，不单独发布 wheel 或 sdist；候选中没有跟踪 wheel、ZIP、sdist、缓存或临时安装目录。
- `build_offline_wheels.ps1` 从 `pyproject.toml` 读取并校验版本，使用锁文件导出运行依赖，为 `win_amd64` / CPython 3.12 下载 binary wheels，并生成包含版本、文件数、总字节、逐文件大小和 SHA-256 的 `wheelhouse-manifest.json`。
- `build_offline_package.ps1` 再次从 `pyproject.toml` 读取版本，逐项校验 wheelhouse 与 manifest 完全一致，把 `VERSION.txt`、安装器、两份宿主模板、v1.12 用户手册和 73 个 wheel 打入单一 ZIP，并生成及回读验证包内 `SHA256SUMS.txt`。
- `install.bat` 从包内 `VERSION.txt` 取得固定 semver，强制 Python 3.12，以 `--no-index --find-links` 安装精确的 `ft-ftp-mcp-stdio==%PACKAGE_VERSION%`，再核对已安装元数据版本并生成、解析宿主模板。
- `scripts/verify_offline_install.py` 核对已安装包版本，启动真实已安装 stdio 进程，核对 MCP server version 和精确 14 工具集合。该验证不连接 FTP/SFTP；它与此前记录的首次安装、重复安装和模板解析证据形成闭环。
