# 产品能力清单 v0.4

> 对应产品版本：`ft-ftp-mcp-stdio 0.3.1`

## 支持范围

- Windows 10/11 x64、Python 3.12、stdio MCP
- FTP 与 SFTP；不支持 FTPS
- Codex 与 WorkBuddy 正式宿主
- 密码、SFTP 私钥及可选私钥口令
- 配置指纹与独立 known-hosts/TOFU

## MCP 工具

14 个工具：`list_servers`、`test_connection`、`list_dir`、`search_files`、`get_file_info`、`read_text_preview`、`download_file`、`upload_file`、`make_dir`、`download_dir`、`upload_dir`、`rename`、`move`、`delete`。

公开结果使用封闭 Schema。业务失败返回 `isError=true` 和 13 类稳定错误之一；框架参数错误保持 `structuredContent=null`。

## 安全与数据完整性

- 配置 v2、root 必填、默认只读
- 虚拟远程路径及真实 root 反向净化
- SFTP 逐段 `lstat` 拒绝链接；FTP 对明确链接执行拒绝或跳过
- 本地上传拒绝 symlink、junction 和 reparse point，并在句柄打开后复核身份
- 上传逐文件限制、同目录临时对象、完成后提交
- 非幂等写操作不盲目重放，无法确认时返回 `outcome_unknown`
- 下载已知大小校验、来源变化检查和部分文件清理
- 批量状态区分 `complete`、`partial`、`failed`，上传另有 `indeterminate`

## 非目标与残余风险

不提供配置 v1 迁移、FTPS、远端哈希保证、事务式批量回滚、全局配额、频率限制、staging 自动清理或本地允许根白名单。并发 `overwrite=false` 与临时名称采用首次检查快照语义，保留 Accepted Spec 和 ADR 0007 已披露的竞态。
