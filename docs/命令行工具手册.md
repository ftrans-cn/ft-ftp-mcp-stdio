## 1. 总览：一个可执行文件，两种身份

```
ft-ftp-mcp-stdio
│
├─ 无参数运行 ────── MCP 服务器（stdio 模式，由客户端拉起）主身份
│                    带任何无效参数则报错退出（退出码 2），不再静默启动
│
└─ 带子命令运行 ─── CLI 运维工具
   ├─ setup                 交互式配置向导
   ├─ doctor [选项]        只读体检诊断
   └─ cred <子命令>        凭据管理
```

## 2. 调用方式

**exe（推荐，绿色免安装）：**

```powershell
& "D:\...\ft-ftp-mcp-stdio.exe" setup
```
路径含空格时 PowerShell 必须用 `&` 调用操作符加双引号，否则路径会被拆断报错。

**pip 安装：**

```powershell
ft-ftp-mcp-stdio setup
# 或
python -m ft_ftp_mcp_stdio setup
```

## 3. setup — 交互式配置向导

可重复运行，改什么存什么，随时退出不影响已有配置。

### 3.1 主菜单

```
1. 添加服务器  2. 修改服务器  3. 删除服务器
4. 切换默认服务器  5. 检测客户端并打印配置片段  6. 设置使用日志  7. 列出服务器  0. 退出
```

菜单 7 为纯本地只读列表：别名、协议、地址：端口、用户名、root、readOnly、凭据方式（钥匙串密码/SFTP 私钥/环境变量）、默认服务器标记。不发起网络连接、不读凭据、不落盘。

### 3.2 服务器字段表（添加/修改共用）

修改时默认值 = 当前配置值，一路回车即"保留现值"。

| # | 字段 | 说明 | 默认值 |
|---|------|------|--------|
| 1 | 别名 | 仅新增时输入；字母开头，字母/数字/`_`/`-`，最长 64 | — |
| 2 | 协议 | `ftp` / `sftp` | ftp |
| 3 | 服务器地址 | 主机名或 IP | — |
| 4 | 端口 | 留空按协议自动取 21 / 22 | 自动 |
| 5 | 用户名 | | — |
| 6 | root | 必填服务器绝对路径；虚拟 `/` 映射到此处；禁止 `.` `..` 段 | `/` |
| 7 | description | 可选非敏感说明，最长 200 字符 | 空 |
| 8 | readOnly | `y` / `n`；仅显式 `n` 启用写操作 | y |
| 9 | 文件名编码 | `auto` / `utf-8` / `gbk` | auto |
| 10 | 单文件上传上限 | 非负字节数；`0` 表示不限制 | 2 GiB |
| 11 | 私钥路径 | 仅 SFTP；留空使用密码认证 | 空 |
| 12 | 主机指纹 | 仅 SFTP；留空使用 TOFU 首连记录 | 空 |
| 13 | 凭据环境变量名 | 留空使用系统钥匙串 | 空 |
| 14 | 密码/私钥口令 | 修改时留空 = 保留现值；设了环境变量名则跳过 | — |

### 3.3 行为细节

- 每一步输入 `b` 返回上一步；第一格输入 `b` 取消回主菜单
- FTP 协议自动跳过私钥路径、主机指纹两项
- **保存前真实连接测试**：连不上不落盘；主机密钥在用户认证前校验
- 遇到非 v2 配置时明确拒绝，不迁移、不覆盖；用户需先自行备份并显式替换
- 原子写入 + 自动备份（`config.json.bak.时间戳`），凭据写入失败自动回滚配置
- 保存成功后自动打印客户端配置片段（菜单 5 同款输出）
- 删除保护：唯一服务器不可删；默认服务器在剩 2 台以上时须先显式切换默认
- 删除服务器时可选是否同时删钥匙串凭据（默认保留）

## 4. doctor — 只读体检

```
ft-ftp-mcp-stdio doctor
ft-ftp-mcp-stdio doctor --server 别名
```

不带 `--server` 检查全部服务器；带则只查一台。**只读，不改任何配置和凭据。**

检查项：

| 层面 | 项目 |
|------|------|
| 全局 | 运行环境（Python 及依赖版本）、使用日志目录可写、配置文件解析 |
| 每台服务器 | 凭据可用性（含来源：钥匙串/环境变量）、TCP 可达、协议登录（真实登录）、FTP 被动模式数据通道 / SFTP 主机指纹核验 |

退出码：任一项 FAIL 返回 1，全部通过返回 0，脚本可据此判断。

SFTP 指纹项首次运行为 WARN（TOFU 记录尚未建立，正常 MCP 连接会原子记录），不是故障。doctor 本身不创建或修改 known-hosts。

## 5. cred — 凭据管理

凭据存 Windows 系统钥匙串，不落盘。

```
ft-ftp-mcp-stdio cred add <别名>      保存/更新密码或私钥口令
ft-ftp-mcp-stdio cred list            列出所有别名 + 凭据状态
ft-ftp-mcp-stdio cred remove <别名>   删除该服务器凭据
```

- `add`：输入不回显。SFTP 私钥场景输入的是口令，**留空 = 无口令密钥**（自动清除已存口令）；密码场景不能为空
- `list` 三态：`configured`（已存）/ `not required`（无口令密钥）/ `missing`（缺失）
- 典型用途：服务器侧改了密码，只需 `cred add 别名` 重输一次，不必重跑 setup

## 6. 环境变量

| 变量 | 用途 | 使用方 |
|------|------|--------|
| `FT_FTP_MCP_CONFIG` | 覆盖配置文件路径（默认 `~/.ft-ftp-mcp/config.json`） | 手动指定时设置 |
| `PYTHONUTF8=1` | 强制 UTF-8 模式，Windows GBK 控制台下中文文件名安全 | 客户端配置 env 段 |
| `FASTMCP_SHOW_SERVER_BANNER=false` | 关闭启动横幅；**Codex 必须设置**，否则拒载 | Codex 客户端配置 |

## 7. 退出码约定

| 码 | 含义 |
|----|------|
| 0 | 成功 / 全部检查通过 |
| 1 | 失败 / doctor 存在 FAIL |
| 2 | 无效参数（server 启动前防呆拦截） |
| 130 | Ctrl+C 中断（配置未改变） |

## 8. 文件位置

| 路径 | 内容 |
|------|------|
| `~/.ft-ftp-mcp/config.json` | 服务器配置（含版本号、默认服务器、staging 目录、日志开关） |
| `~/.ft-ftp-mcp/config.json.bak.*` | 每次修改的自动备份 |
| `~/.ft-ftp-mcp/staging/` | 传输暂存目录 |
| `~/.ft-ftp-mcp/known_hosts` | SFTP TOFU 指纹记录 |
| `~/.ft-ftp-mcp/logs/` | JSONL 使用日志（按日期分文件，不含凭据） |

## 9. 典型维护场景（指令组合）

| 场景 | 操作 |
|------|------|
| 新增 SFTP 服务器（密钥认证） | `setup` → 1 → 协议 sftp → 私钥路径填 `D:\.ssh\私钥` → 口令留空（无口令私钥）→ 自动连接测试保存 |
| 服务器改密码 | `cred add 别名` 输新密码 → `doctor --server 别名` 验证 |
| 临时调大单文件上传上限 | `setup` → 2 → 选别名 → 一路回车保留现值，仅改上限字段 |
| 换默认服务器 | `setup` → 4 → 选别名 |
| 下线服务器 | `setup` → 4 先切默认（>2 台时）→ 3 删除（凭据默认保留） |
| 改端口/用户名不动凭据 | `setup` → 2 → 改字段 → 密码一步留空即保留现值 |
| 换用环境变量凭据（CI） | `setup` → 2 → 凭据环境变量名填变量名 → secret 步自动跳过 |

## 10. 注意事项

- 日常调整（端口/上限/root）不必重输密码：修改时密码留空 = 保留现值
- 配置每步改动自动备份，控制台打印"原配置备份：<路径>"；出问题可手动回滚
- 凭据写钥匙串失败时配置自动回滚，不会出现"配置有服务器、凭据缺失"的半状态
- `cred list` 会先加载 config.json；没有配置文件时不能当纯凭据自检命令
